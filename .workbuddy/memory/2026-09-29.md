# 2026-09-29 便携桌面 1.1.1 发布（便携版 + 安装包版）

## 交付物（均含昨日 GPU 修复）
- 便携版：`publish-selfcontained/PortableDesktop.exe`（62.7MB 自包含单文件，双击即用）
- 框架依赖版：`publish/`（170KB，需目标机有 .NET 9 桌面运行时）
- 安装包版：`installer/PortableDesktop-1.1.1-Setup.msi`（56.9MB，WiX 6.0.2 构建）
- **单文件 EXE 安装包**：`installer/PortableDesktop-Setup-v1.1.1.exe`（57.7MB，Burn 引导）
  —— 老板点名要的"能选安装地址的那种 exe"，方案照搬 OpsHelper：
  Bundle.wxs + hyperlinkLargeLicense 主题（Options 页有目录浏览）+ zh-CN.wxl 中文字符串表
  （直接复用 OpsHelper 的，字符串全用 [WixBundleName] 占位，无需改）
  - 构建：cd installer && `python ../.dotnet.py wix build Bundle.wxs -arch x64
    -ext WixToolset.BootstrapperApplications.wixext -culture zh-CN
    -d IconFile=<abs> -d MsiFile=<abs> -d LocFile=zh-CN.wxl
    -pdb PortableDesktop-Bundle.wixpdb -o PortableDesktop-Setup-v1.1.1.exe`
  - Bundle UpgradeCode=BEFCD536-A5AC-4D3A-A370-AC63836C8F43（升级别改）
  - InstallFolder 变量照抄 OpsHelper 的 SetVariable 模式（string 变量不展开的坑已规避）
  - 中文 UI 已验证可行（同一主题+同一字符串表在 OpsHelper 实测过）；沙箱内无法点 UI，实装体验留给老板

## csproj 变更
- 加 `<Version>1.1.1</Version>`（exe FileVersion/ProductVersion 已验证 1.1.1）

## MSI 设计
- perUser 免管理员，装 `%LocalAppData%\Programs\PortableDesktop`
- 内嵌自包含 exe（SHA256 与 publish-selfcontained 逐字节一致，已 msiexec /a 解包验证）
- 开始菜单分组 + 桌面快捷方式；util:CloseApplication 处理运行中实例
- 卸载只删安装目录，用户数据（%LocalAppData%\PortableDesktop）保留
- UpgradeCode=1344FB98-5A32-461C-AF57-783BF6219527（以后升级别改）

## 踩坑记录
1. WiX v7 要接受 OSMF 付费维护费 EULA —— 雷区，锁死 6.0.2
2. 扩展不带版本号会拉 7.0.0（与 wix 6 不兼容，WIX6101 警告），要 `xxx/6.0.2`
3. `wix build` 没有 `-codepage` 开关了，中文要用 `Package/@Codepage="936"`（默认 1252 直接报 WIX0311）
4. **Icon 表引用主 exe 当图标源会把 60MB 文件原样再嵌一份**，MSI 从 119MB 降到 57MB 就是修的这个
5. 发布时 publish-selfcontained 的 exe 被占用（老板正在运行的实例）——发布前先查
   `Get-Process PortableDesktop | Select Path`，确认再关，别盲杀
6. 验证方式：`msiexec /a /qn TARGETDIR=<temp>` 管理解包（不落地安装）；
   装卸行为回归用 Bundle 的 `/install /quiet` + `/uninstall /quiet`（自己的软件、
   自己的用户目录，装完可完整卸载，状态能恢复）

# 2026-09-29（下午）1.1.2：修「不会自动新建文件夹 + 卸载不清理」

## 老板反馈
「你这安装程序为什么不会自动新建文件夹安装，卸载时也不会清理程序」

## 排查：把 1.1.1 装了/卸了三遍，全部实机（不是推测）
- **默认位置**安装 -> ✅ 建 `%LocalAppData%\Programs\PortableDesktop`；
  卸载后目录/桌面快捷方式/开始菜单/卸载注册项/Package Cache **全清**，数据目录按设计保留
- **程序运行中**卸载 -> ✅ 进程被 util:CloseApplication 关掉，文件全删
- **装到已有内容的目录** -> ❌ `PortableDesktop.exe` **直接铺进去跟用户文件混在一起**；
  卸载后那个目录**还在**（因为里面有用户自己的文件）
→ 完全对上老板那两句话。根因：**「安装位置」被当成最终安装目录，不是父目录。**

## 修复（1.1.2）
`installer/Bundle.wxs` 把 InstallFolder 语义改成【父目录】：
- SetVariable 默认值 `[LocalAppDataFolder]Programs`（原来带 `\PortableDesktop`）
- `MsiProperty INSTALLFOLDER = [InstallFolder]\PortableDesktop`（原来直接 `[InstallFolder]`）
- LaunchTarget = `[InstallFolder]\PortableDesktop\PortableDesktop.exe`
- `zh-CN.wxl`：`OptionsLocationLabel` 改「安装位置（将新建「便携桌面」子文件夹）：」，
  `InstallMessageOptions` 同步加说明
- 版本号 1.1.1 -> 1.1.2（csproj + 两个 wxs），否则同版本重装 Burn 不认为是升级

## 实测验证（1.1.2，全绿）
- 默认安装 -> 仍装 `...\Programs\PortableDesktop` ✅；卸载干净 ✅
- 父目录指向有用户文件的目录 -> **自动建 `PortableDesktop\` 子文件夹** ✅；
  卸载后子文件夹清掉、用户自己的文件原样保留 ✅
- 选项页文字（UIA 读控件 + 截图）确认

## 新增可复用工具
- `Probe/shot_setup_ui.py`：开安装程序 UI -> 截图 + 读控件文字 -> 关闭（**不点安装**）。
  从 OpsHelper/Probe/shot_zh_ui.py 移植；5 个坑（界面在 wixstdba 子进程、窗口先 0x0、
  ctypes 句柄必须声明 argtypes、UIA 子线程要 UIAutomationInitializerInThread、
  点击只能用 UIA InvokePattern）见技能 `wixstdba-ui-verification-windows`
- `Probe/e2e_install.py`、`Probe/e2e_verify_folder.py`：静默装/卸 + 目录结构断言

## 坑（重要）
- **沙箱禁止在工作区外创建目录**（`D:\` 根直接 Permission denied），MSI 会报
  **1303「没有足够的特权来访问目录」**。这是**沙箱伪影，不是真实环境问题** ——
  做安装位置实验必须选工作区内的目录，否则会误判成权限 bug。
- 用户级(perUser)安装确实没有管理员权限：真选到 Program Files 之类的位置会真失败(1303)。
- 顺手修：`.gitignore` 原来整目录忽略 `installer/`，把 `Bundle.wxs` / `zh-CN.wxl`
  两个**源文件**也挡在版本库外了，改成只忽略 `*.msi` / `*.exe` / `*.wixpdb`。
- 遗留：安装程序窗口标题栏图标显示成通用图标（不是四色 logo），不影响功能，未处理。
