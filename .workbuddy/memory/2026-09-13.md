## 用户诉求与落点
1. **图标在卡片里顶格偏上** —— 根因：`StackPanel` 塞进固定高 90 的卡片，内容从顶部堆叠，底部空约 24px。
   改为两行 `Grid`（`*`/`Auto`），图标盘放弹性行 `VerticalAlignment=Center`、名称贴底。卡片尺寸 90×90 → 98×110。
2. **优化代码** —— 新增 `Controls/ItemCard.xaml(.cs)`（卡片从 106 行命令式 C# 变声明式 XAML）、
   `Models/ThemeCatalog.cs`（主题单一真源）、`Themes/Shared.xaml`（结构与颜色分层）。
   `MainWindow.xaml.cs` 删掉全部 `CreateItemCard`/`FindResource` 取色代码，改 `ItemsControl` + `ObservableCollection` 绑定。
3. **增加动效** —— 窗口淡入上浮、卡片错峰入场(30ms)、悬停 scale1.055+投影加深、按下 0.94 回弹(BackEase)、
   主题切换渐显、拖拽遮罩淡入淡出、空状态呼吸、窗口按钮缩放、右键菜单圆角。
4. **顺手修的缺陷** —— 非 .lnk 文件取不到图标（改用 `SHGetFileInfo`）、HICON 句柄泄漏、
   图标无缓存、设置高频落盘（加 400ms 防抖）、拖拽遮罩闪烁（改 `PreviewDragOver` + 140ms 空闲判定）、
   最大化时残留圆角/阴影、`MaxButton.Content` 裸 PUA 字符改显式转义、右键菜单新增「打开所在文件夹」。

## 关键约定（后续改动请沿用）
- **主题只放颜色，结构放 `Themes/Shared.xaml`**；切主题时按 `Source` 定位并原地替换主题字典，不要 `Clear()`。
- 四套主题的键集合必须一致（新增键要同时补 4 个文件）。
- 卡片布局约束：卡片 98×110、圆角 16；图标盘 56×56/圆角 18；图标 32px；名称贴底、`MaxWidth=84`。

## 本机编译校验命令（沙箱内 NuGet 不可用）
```bash
dotnet build PortableDesktop/PortableDesktop.csproj -c Debug --no-restore \
  -p:SkipResolvePackageAssets=true -p:GenerateDependencyFile=false -p:GenerateRuntimeConfigurationFiles=false
```
结果：**0 警告 0 错误**；8 个 XAML 全部生成 BAML（`obj/Debug/net9.0-windows/**/*.baml`）。
注意：这条命令产不出可运行 exe，正常环境直接 `dotnet build` / `dotnet run` 即可，无需任何参数。
`bin/` 拷贝会失败——用户当时正开着旧版程序占用了 `bin/Debug/net9.0-windows/PortableDesktop.dll`。
