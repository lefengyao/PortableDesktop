① 本次修复的核心：图标不再顶格

旧版把「图标 + 名称」的 StackPanel 直接塞进固定 90px 高的卡片，内容按自然顺序从顶部往下堆， 图标被顶到最上面，底部空出约 22px，看起来"头重脚轻"。
新版把图标盘放进弹性行 VerticalAlignment="Center"，名称固定在底部 —— 图标在剩余空间里垂直居中，留白上下均衡。
